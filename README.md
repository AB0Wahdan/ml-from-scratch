# 🔢 ML From Scratch

> Classic machine learning algorithms implemented without ML libraries

![Python](https://img.shields.io/badge/Python-1f6feb?style=flat-square) ![NumPy](https://img.shields.io/badge/NumPy-1f6feb?style=flat-square) ![Matplotlib](https://img.shields.io/badge/Matplotlib-1f6feb?style=flat-square)

## 📌 Overview
Implementations of core ML algorithms using only Python and NumPy, to understand exactly how they work under the hood.

## ✨ Features
- Linear Regression (gradient descent)
- Decision Tree (information gain)
- K-Nearest Neighbors
- Comparison against scikit-learn results

## 🛠️ Tech Stack
Python, NumPy, Matplotlib

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python linear_regression.py
```
